1- criar o projeto com: npx create-expo-app --template blank "nome do projeto"
obs: rodar no terminal dentro da pasta onde deseja criar o projeto.

2- escolher a versão 55 do sdk (setas para cima e baixo)

3- depois de criado o projeto, criar o banco de dados no firebase

4- depois de ter feito o passo a passo e registrado o app cole o primeiro comando do firebase:
npm install firebase

5- copiar as configurações (script) do firebase para um arquivo jsx 
(firebaseConnection.jsx) ja dentro de uma pasta src

6- adicionar a importaçao:
   import {getFirestore} from 'firebase/firestore'
   no firebaseConnection.jsx
   fazer o mesmo com as duas linhas abaixo:
   const db = getFirestore(app);

   export default { db };

7- rodar o comando (por garantia):
   npx expo customize metro.config.js
   e adicionar o script:
   config.resolver.sourceExts.push('cjs'); abaixo do const config...
